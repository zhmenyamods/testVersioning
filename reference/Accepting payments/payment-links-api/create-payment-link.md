title: Create payment link
excerpt: >-
  With the Payment links API you can generate payment links that by default,
  unlike regular payments, do not expire. The payment link can be shared with
  your customers and will redirect them to them the payment page where they can
  complete the payment. A [payment](get-payment) will only be created once the
  customer initiates the payment.
